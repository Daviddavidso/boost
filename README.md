# BOOST — витрина финансовых продуктов

Статичный сайт-каталог + панель управления. Никаких сборок и зависимостей:
файлы кладутся на хостинг как есть, нужен только PHP (для панели).

```
index.html          сайт
admin.html          панель управления
data.js             каталог: категории и предложения
api.php             бэкенд панели (вход + запись data.js)
config.php          пароль от панели  ← поменять!
assets/style.css    оформление сайта
assets/app.js       поиск, фильтр, сортировка, подбор
assets/admin.css    оформление панели
assets/admin.js     логика панели
.htaccess           кэш, сжатие, закрытие служебных файлов
```

## Панель управления

Адрес: `/admin.html`, пароль по умолчанию — `boost2026`.

**Первым делом поменяйте пароль** в файле `config.php`:

```php
return [
    'password' => 'свой-пароль',
];
```

Что умеет панель:

- добавлять, править, удалять и переставлять предложения;
- добавлять и переставлять категории (порядок = порядок кнопок фильтра на сайте);
- кнопка «Сохранить и опубликовать» переписывает `data.js` прямо на сервере —
  правки видны посетителям сразу, ничего заливать по FTP не нужно;
- «Резервная копия (JSON)» и «Загрузить копию» — на случай, если что-то сломалось;
- «Выгрузить data.js» — файл для ручной заливки.

Перед каждой записью прошлая версия каталога сохраняется в `data.backup.js`.

Если PHP на хостинге нет или панель открыта файлом с диска, она сама
переключается в запасной режим: правки живут в браузере, каталог выгружается
файлом `data.js` и заливается вручную.

## Поля предложения

| Поле | Что это |
|---|---|
| Категория | из списка категорий |
| Название компании | крупная строка на карточке |
| Подзаголовок | название продукта под ней |
| Плашка | оранжевый ярлык в углу, можно оставить пустым |
| Описание | 1–2 предложения |
| Параметры | строки вида `Сумма \| до 100 000 ₽`, до шести штук |
| Партнёрская ссылка | куда ведёт кнопка «Оформить» |

Сортировка «по сумме» и «по ставке» читает числа прямо из параметров
(`Сумма`, `Лимит`, `Покрытие`, `Ставка`), поэтому пишите значения обычным
текстом — «до 100 000 ₽», «от 19,9% годовых». Ставку «в день» сайт сам
приводит к годовой, чтобы сравнение было честным.

## Установка на хостинг

1. Залить все файлы в корень сайта.
2. Поставить `data.js` права **664** — иначе панель не сможет его переписать.
3. Открыть `/admin.html`, войти, поменять пароль в `config.php`.
4. Проверить, что `https://ваш-домен/config.php` отдаёт 403 (это делает `.htaccess`).

## Что нужно заменить перед запуском

- **Ссылки в каталоге** — сейчас это официальные сайты компаний, поставьте свои
  партнёрские ссылки.
- **Цифры в параметрах** — типовые, сверьте с условиями партнёрки.
- Название и домен, если нужно другое.

## Локальный запуск

```bash
php -S 127.0.0.1:4500 -t .
```

Сайт — <http://127.0.0.1:4500/>, панель — <http://127.0.0.1:4500/admin.html>.

## Доступность

Свёрстано под WCAG 2.1 AA: контраст текста от 4.9:1, все элементы управления
работают с клавиатуры, у бегущей строки есть кнопка остановки, анимации
выключаются при системной настройке «уменьшить движение», результаты фильтра
и удаление позиций объявляются скринридеру.
